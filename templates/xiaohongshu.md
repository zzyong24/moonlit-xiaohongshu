# 小红书图文模板

> **默认**：生成并发布 **1 张封面图 + 配文**。只有每张后续图都能提供独立步骤、证据、数据或对照时，才使用多图模式。

---

## 文件名格式

```
MMDDHHMM-[纯中文主题]-小红书.md
```

---

## 封面图（1 张）

**必须包含**：
- 钩子图（assets/1-封面-XXX.png 复用）
- "月明水清深"小角标
- 品牌令牌亮色 `paper` 主题：暖白底 + 深蓝标题 + 铜橙强调 + 本人真实形象 + 本期具体证据（不用宇航员或科技绿）

## 模板

```markdown
# 【小红书图文 · 单封面图 + 配文】

## 配文（≤500 字）

【开头 · 钩子 1–2 句：结果型 / 数字型 / 问题型 选一种】

[展开 200–300 字 · 一个主要收获；需要时 2–4 个 bullet]

【结尾 · 自然结束，或给实际存在的项目/资产链接；不默认评论扣词】

## 标签（5-8 个）

#AI工具 #一人公司 #产品化落地 #内容创作 #月明水清深

## 发布字段

- imageMode: single_cover
- originalityPolicy: ask_each_run
- contentTypeDeclaration: 笔记含AI合成内容
- visibility: public

## 封面图

![封面](assets/1-封面-XXX.png)

## 上传图片

1. [封面路径]

> `single_cover` 只允许 1 张图。切换为 `carousel` 时列出 2–18 张真实路径，并说明每张图不可替代的信息价值。
```

---

## 配文要点

- **开头 1-2 句**抓人（含数字/emoji/反常识）
- **正文 200-300 字**：3 个 bullet + 1 句话总结
- **结尾 CTA**：评论扣关键词
- **标签**：5-8 个，含话题标签 + 长尾词 + 品牌词

## 自检清单

- [ ] 配文 ≤500 字
- [ ] 标题含数字/emoji/情绪词
- [ ] 开头 1-2 句抓人
- [ ] 标签 5-8 个
- [ ] 封面图已指定（assets/1-XXX.png）
- [ ] `single_cover` 只有 1 张图，路径存在
- [ ] 若为 `carousel`，2–18 张图片路径存在、顺序明确且没有凑数图
